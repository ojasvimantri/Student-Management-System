# Student Management System in C++

## Project Description
The Student Management System is a console-based application developed using C++. It manages student records through a simple menu-driven interface.

## Features
- Add a student
- Display all students
- Search students by roll number
- Update student marks
- Delete student records
- Display Pass/Fail result
- Prevent duplicate roll numbers
- Count student objects

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- VS Code
- Git and GitHub

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Static Data Members
- Friend Function
- Virtual Destructor

## How to Compile and Run

Compile the program:

```bash
g++ main.cpp -o student
```

Run on Windows PowerShell:

```powershell
.\student.exe
```
